# Security policy

Please do not publish API keys, GitHub tokens, screenshots containing secrets, or signing files in issues or commits.

Report vulnerabilities privately through **GitHub → Security → Report a vulnerability**. Include the app version, Android version, reproduction steps, and impact. Do not attach real credentials.

OpenRouter credentials are sent only to the configured OpenRouter HTTPS endpoint. Screen crops are processed locally unless a cloud OCR/translation engine is selected; cloud engines receive the selected crop or recognized text.
